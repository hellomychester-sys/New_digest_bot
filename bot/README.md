# News Digest Bot

Telegram-бот, который по команде `/digest` собирает новости за последнюю
календарную неделю по заданным темам и присылает **PDF-файл с единой таблицей**
(Тема / Краткое саммари / Ссылка на источник), а под таблицей — блок с тем,
как эти находки можно применить к продукту в сфере **oral care** (уход за
полостью рта).

- Поиск новостей — через встроенный веб-поиск Claude API.
- Темы можно добавлять/удалять прямо командами в Telegram.
- Запуск — только по вашей команде `/digest`, никакого автоматического
  расписания нет.
- Контекст "продукт в сфере oral care" учитывается моделью всегда, без
  дополнительной настройки. Командой `/context` можно добавить что-то ещё
  сверху (например, конкретный тип устройства или аудиторию).

---

## Важный момент про адрес `https://t.me/hellomychester`

Бот не может писать первым в произвольный чат по ссылке на профиль. Вы
создаёте своего бота через @BotFather, один раз пишете ему `/start` под
своим аккаунтом — и дальше `/digest` присылает файл в этот же чат.

---

## Что нужно для запуска

1. **Токен Telegram-бота** — из @BotFather (`/newbot`).
2. **Ключ Anthropic API** — из console.anthropic.com, с привязанным способом
   оплаты и пополненным балансом (у API нет бесплатного тарифа навсегда).

Оба значения задаются как переменные окружения: `BOT_TOKEN` и
`ANTHROPIC_API_KEY` (в Railway — вкладка Variables; локально — файл `.env`
по образцу `.env.example`).

---

## Команды бота в Telegram

| Команда | Что делает |
|---|---|
| `/start` | Зарегистрировать этот чат для получения дайджестов |
| `/digest` | Собрать новости за последнюю неделю и прислать PDF-таблицу |
| `/add <тема>` | Добавить тему или ключевые слова |
| `/remove <тема>` | Удалить тему |
| `/list` | Показать текущий список тем |
| `/context <текст>` | Добавить контекст сверх oral care (необязательно) |
| `/help` | Справка по командам |

## Как это работает

- `bot/ai_digest.py` — при `/digest` формирует запрос к Claude API с
  веб-поиском (`web_search_20250305`). Системный промпт просит модель найти
  реальные новости за 7 дней по каждой теме и вернуть **строго JSON**:
  плоский список `{topic, summary, link}` плюс поле `insights` с выводами
  для oral care. Модель всегда знает про контекст продукта — это зашито в
  системный промпт (`BASE_PRODUCT_CONTEXT`).
- `bot/pdf_render.py` — превращает эти данные в PDF: таблица из трёх колонок
  + блок выводов. Кириллица работает через шрифт DejaVu Sans, который берётся
  из пакета `matplotlib` (используется только как источник файла шрифта).
- `bot/handlers.py` — обрабатывает команды, вызывает генерацию и сборку PDF,
  отправляет файл в Telegram.
- `bot/storage.py` — хранит chat_id, темы и дополнительный контекст в
  `data/state.json`.

## Настройка

- Модель — переменная окружения `ANTHROPIC_MODEL` (по умолчанию
  `claude-sonnet-5`).
- Число новостей на тему (по умолчанию до 4) и глубина поиска — в
  `bot/ai_digest.py`.
- Ширина колонок и стили таблицы — в `bot/pdf_render.py` (`col_widths`,
  `TableStyle`).
- Формулировка фиксированного контекста продукта — переменная
  `BASE_PRODUCT_CONTEXT` в `bot/ai_digest.py`, если направление продукта
  изменится.

## Важно про сборку образа

В `requirements.txt` добавлены `reportlab` (сборка PDF) и `matplotlib`
(источник шрифта с кириллицей). `matplotlib` — довольно тяжёлая библиотека,
поэтому первая сборка образа в Railway может занять на 1-2 минуты дольше,
чем раньше. Это ожидаемо и не является ошибкой.

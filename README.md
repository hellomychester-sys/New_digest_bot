# News Digest Bot

Telegram-бот, который по вашей команде `/digest` собирает новости за последнюю
календарную неделю по заданным темам и присылает готовый markdown-дайджест
файлом в чат — в том же формате (разделы по темам, даты, источники, блок
итоговых наблюдений), что и ручной дайджест.

- Поиск новостей — через встроенный веб-поиск Claude API (реальный поиск в
  интернете за нужный диапазон дат, а не просто RSS-лента).
- Темы можно добавлять/удалять прямо командами в Telegram.
- **Запуск — только по вашей команде**, никакого автоматического расписания
  нет: вы сами решаете, когда прислать дайджест.

**Команды бота в Telegram**

| Команда | Что делает |
|---|---|
| `/start` | Зарегистрировать этот чат для получения дайджестов |
| `/digest` | Собрать новости за последнюю неделю по всем текущим темам и прислать файл |
| `/add <тема>` | Добавить тему или ключевые слова, например: `/add умные часы здоровье` |
| `/remove <тема>` | Удалить тему (текст должен совпадать с тем, что в `/list`) |
| `/list` | Показать текущий список тем |
| `/context <текст>` | Описать ваш продукт/интересы — дайджест будет 1-2 наблюдения явно связывать с этим контекстом |
| `/help` | Справка по командам |

Пример:
```
/context Развиваю умную стельку с приложением для превентивного мониторинга
неврологических и психологических рисков. Интересны гипотезы, подписочные
модели и работа с тревожной аудиторией.
```

---

## Как это работает

- `bot/ai_digest.py` — при команде `/digest` формирует запрос к Claude API
  с включённым инструментом веб-поиска (`web_search_20250305`) и системным
  промптом, который просит найти реальные новости за последние 7 дней по
  каждой теме, сгруппировать их и оформить в Markdown с разделом «Итоговые
  наблюдения» в конце — аналогично формату ручного дайджеста.
- `bot/handlers.py` — обрабатывает команды, сохраняет получившийся текст во
  временный `.md`-файл и отправляет его в Telegram как документ.
- `bot/storage.py` — хранит chat_id, список тем и опциональный контекст о
  продукте в `data/state.json`.
- Автоматического расписания в коде нет — генерация запускается только
  обработчиком команды `/digest`.

## Настройка модели / глубины поиска

- Модель задаётся переменной окружения `ANTHROPIC_MODEL` (по умолчанию
  `claude-sonnet-5`) — можно поменять в `.env`.
- Максимальное число новостей на тему (по умолчанию 5) и глубина поиска
  (`max_uses` для веб-поиска, по умолчанию 20 запросов за один дайджест)
  настраиваются в `bot/ai_digest.py`.

## Возможные доработки

- Если всё же захочется вернуть автоматическую еженедельную отправку —
  в `python-telegram-bot` есть встроенный `JobQueue.run_daily(...)`, куда
  можно передать тот же вызов `generate_digest()`, что используется в `/digest`.
- Хранить несколько получателей вместо одного `chat_id`, если решите
  добавить коллег в рассылку.
- Добавить `allowed_domains`/`blocked_domains` в параметры веб-поиска в
  `ai_digest.py`, если захотите ограничить круг источников.

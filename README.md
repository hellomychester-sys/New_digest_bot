# News Digest Bot

Telegram-бот, который по вашей команде `/digest` собирает новости за последнюю
календарную неделю по заданным темам и присылает готовый markdown-дайджест
файлом в чат — в том же формате (разделы по темам, даты, источники, блок
итоговых наблюдений), что и ручной дайджест.

- Поиск новостей — через встроенный веб-поиск Claude API (реальный поиск в
  интернете за нужный диапазон дат, а не просто RSS-лента).
- Темы можно добавлять/удалять прямо командами в Telegram.
- **Запуск — только по вашей команде**, никакого автоматического расписания
  нет: вы сами решаете, когда прислать дайджест.

---

## Важный момент про адрес `https://t.me/hellomychester`

Бот не может писать первым в произвольный чат по ссылке на профиль — это
ограничение Telegram, а не бота. Работает это так:

1. Вы создаёте **своего** бота через @BotFather (см. шаг 1) — у него будет
   отдельный username вида `@my_news_digest_bot`.
2. Открываете чат с этим ботом **под своим аккаунтом** (тем самым
   `hellomychester`) и один раз отправляете `/start`.
3. С этого момента бот запоминает ваш chat_id, и когда вы пришлёте ему
   `/digest`, ответ придёт в этот же чат.

## Раз запуска по расписанию больше нет — деплой стал проще

Так как дайджест собирается только по вашей команде, **бот не обязан работать
24/7**. Можно:

- либо запускать его на своём компьютере ровно в те моменты, когда хотите
  получить дайджест (запустили `python main.py`, отправили `/digest`,
  дождались файла, закрыли);
- либо один раз задеплоить его в облако, чтобы он всегда был под рукой и
  реагировал на `/digest` мгновенно, в любой момент.

Ниже — оба варианта.

---

## Шаг 1. Получить два ключа

### 1.1. Токен Telegram-бота

1. В Telegram откройте **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

### 1.2. Ключ Anthropic API

1. Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com).
2. В разделе **API Keys** создайте новый ключ (вида `sk-ant-...`).
3. Пополните баланс — веб-поиск и генерация дайджеста тарифицируются по
   использованию API (это отдельный сервис от вашей обычной подписки на
   claude.ai, если она у вас есть).

---

## Шаг 2. Настроить проект

1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` и вставьте оба ключа:
   ```
   BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
3. Список тем по умолчанию — в `bot/storage.py` (`DEFAULT_TOPICS`), можно
   отредактировать сразу или поменять позже командой `/add` прямо в Telegram.

---

## Шаг 3а. Запуск на своём компьютере (самый простой вариант)

Подходит, если вам достаточно запускать бота вручную перед тем, как попросить
дайджест.

```bash
python -m venv venv
source venv/bin/activate   # на Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Пока в терминале видно строку `Бот запущен, ждёт команд...` — бот работает.
Идёте в Telegram, пишете `/start`, потом `/digest`. Закончили — `Ctrl+C` в
терминале, чтобы остановить.

---

## Шаг 3б. Постоянный запуск в облаке (чтобы бот был готов в любой момент)

Если хочется, чтобы бот всегда отвечал мгновенно, не открывая терминал —
вариант на **Railway.app** (без настройки серверов руками):

1. Зарегистрируйтесь на [railway.app](https://railway.app) (можно через GitHub).
2. Залейте эту папку в свой репозиторий на GitHub (в веб-интерфейсе GitHub —
   кнопка "Add file → Upload files", консоль не нужна).
3. В Railway: **New Project → Deploy from GitHub repo** → выберите репозиторий.
4. Railway сам увидит `Dockerfile` и соберёт контейнер.
5. Во вкладке **Variables** добавьте `BOT_TOKEN` и `ANTHROPIC_API_KEY` —
   в облаке ключи задаются через интерфейс, а не через `.env`-файл.
6. Во вкладке **Settings → Volumes** подключите volume в `/app/data`, чтобы
   темы не терялись при обновлении деплоя.
7. Дождитесь статуса **Deployed** — бот работает постоянно и готов принимать
   `/digest` в любой момент.

### Альтернатива — свой VPS через Docker

```bash
git clone <ваш-репозиторий> news-bot
cd news-bot
cp .env.example .env   # впишите BOT_TOKEN и ANTHROPIC_API_KEY
docker compose up -d --build
```

## Команды бота в Telegram

| Команда | Что делает |
|---|---|
| `/start` | Зарегистрировать этот чат для получения дайджестов |
| `/digest` | Собрать новости за последнюю неделю по всем текущим темам и прислать файл |
| `/add <тема>` | Добавить тему или ключевые слова, например: `/add умные часы здоровье` |
| `/remove <тема>` | Удалить тему (текст должен совпадать с тем, что в `/list`) |
| `/list` | Показать текущий список тем |
| `/context <текст>` | Описать ваш продукт/интересы — дайджест будет 1-2 наблюдения явно связывать с этим контекстом |
| `/help` | Справка по командам |

Пример:
```
/context Развиваю умную стельку с приложением для превентивного мониторинга
неврологических и психологических рисков. Интересны гипотезы, подписочные
модели и работа с тревожной аудиторией.
```

## Как это работает

- `bot/ai_digest.py` — при команде `/digest` формирует запрос к Claude API
  с включённым инструментом веб-поиска (`web_search_20250305`) и системным
  промптом, который просит найти реальные новости за последние 7 дней по
  каждой теме, сгруппировать их и оформить в Markdown с разделом «Итоговые
  наблюдения» в конце — аналогично формату ручного дайджеста.
- `bot/handlers.py` — обрабатывает команды, сохраняет получившийся текст во
  временный `.md`-файл и отправляет его в Telegram как документ.
- `bot/storage.py` — хранит chat_id, список тем и опциональный контекст о
  продукте в `data/state.json`.
- Автоматического расписания в коде нет — генерация запускается только
  обработчиком команды `/digest`.

## Настройка модели / глубины поиска

- Модель задаётся переменной окружения `ANTHROPIC_MODEL` (по умолчанию
  `claude-sonnet-5`) — можно поменять в `.env`.
- Максимальное число новостей на тему (по умолчанию 5) и глубина поиска
  (`max_uses` для веб-поиска, по умолчанию 20 запросов за один дайджест)
  настраиваются в `bot/ai_digest.py`.

## Возможные доработки

- Если всё же захочется вернуть автоматическую еженедельную отправку —
  в `python-telegram-bot` есть встроенный `JobQueue.run_daily(...)`, куда
  можно передать тот же вызов `generate_digest()`, что используется в `/digest`.
- Хранить несколько получателей вместо одного `chat_id`, если решите
  добавить коллег в рассылку.
- Добавить `allowed_domains`/`blocked_domains` в параметры веб-поиска в
  `ai_digest.py`, если захотите ограничить круг источников.
